# Pharma Stock Predictor

Application web construite avec Vite + React + TypeScript.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Développement local

Prérequis : Node.js et npm.

```sh
# Cloner le dépôt
git clone <YOUR_GIT_URL>

# Aller dans le dossier
cd <YOUR_PROJECT_NAME>

# Installer les dépendances
npm install

# Lancer le serveur de dev
npm run dev
```

## Déploiement

Cette application est hébergée sur **Netlify**.
